Organize Firefox tabs into native groups with local, ordered rules.

- Preview and consolidate normal windows while preserving pinned tabs and groups.
- Use built-in starter rules or create a custom set with match exclusions.
- Merge exact-name groups and place unmatched tabs after groups.
- Sort selected tabs directly from the tab context menu.
- Undo the latest action, with confirmation if tracked tabs changed afterward.
- Import and export rules and optionally export a sanitized tab inventory.
- Use toolbar icons that adapt to light and dark themes.

Requires desktop Firefox 140 or newer. All processing stays inside Firefox.

Public installation is pending Mozilla signing and the AMO listing. The source
ZIP from GitHub is intended for development and cannot be permanently installed
in standard Firefox.

When replacing the development extension, export your custom rules first. The
permanent extension ID uses separate storage, so import those rules after
installation. Disable the development extension to avoid duplicate menus.
